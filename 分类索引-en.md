# OpenClaw Category Index

OpenClaw-related files are now grouped into four folders:

- `入口/`  
  Start here. Help, reference, and read-only inspection files.
- `诊断/`  
  Status checks, parameter searches, test runs, and collection helpers.
- `修复/`  
  Cleanup, restore, limit, toggle, and environment-fix scripts.
- `日志/`  
  Runtime logs, collected logs, and execution records.
