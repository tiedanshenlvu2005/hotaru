神驴语音输入说明

结论：
现在 Codex 不能直接听见你的原始声音，也不能识别声纹。
但是可以通过“电脑语音输入”把你说的话变成文字，再交给 Codex。

你现在推荐使用的方法：
1. 打开 Codex 聊天输入框。
2. 按键盘 Win + H。
3. 电脑会打开 Windows 语音输入。
4. 你说中文或日语。
5. 系统把声音转成文字后，Codex 就能读懂并执行。

适合说给 Codex 的口令：
神驴，使用 Superpowers 的方式，先调研，再写方案，最后执行。

常用语音任务：
- 神驴，帮我整理这个文件夹。
- 神驴，帮我写一份文档。
- 神驴，帮我检查这个软件有没有用。
- 神驴，帮我做一个页面。
- 神驴，先不要执行，先告诉我方案和风险。

注意：
1. Codex 看到的是文字，不是声音本身。
2. 不要把密码、付款信息、API Key 直接念出来。
3. 如果语音转文字错了，先手动改一下再发送。
4. 删除文件、覆盖文件、付款、发布之前，要先确认。

如果 Win + H 没反应：
1. 点击 Windows 设置。
2. 找到 时间和语言。
3. 找到 语音 或 输入。
4. 打开语音输入相关功能。
5. 检查麦克风是否允许使用。

日语学习用法：
你可以直接说日语句子，让 Codex 帮你：
- 分析语法
- 改正表达
- 做 N1 句型练习
- 生成例句
- 做中日互译

推荐工作方式：
先用语音把想法说出来，再让 Codex 整理成正式任务。
例如：
神驴，我先随便说，你帮我整理成任务清单，不要立刻执行。
