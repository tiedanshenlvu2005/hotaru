# Codex Efficiency Checklist

This is a do-it-now checklist, not a note to keep around. The goal is simple: fewer switches, fewer repeated decisions, fewer competing entry points.

## 1. Use one main homepage

Open `文件总览.html` first. Do not bounce through multiple folders.
The homepage is the navigator; everything else is content.

## 2. Always read in the same order

Use this order every time:

1. `Codex每日执行方针.txt`
2. `AGENTS.md`
3. `PRD.md`
4. `分类索引.md`
5. `执行顺序.md`

## 3. Separate rules, goals, and actions

- `Codex每日执行方针.txt`: how to use it
- `AGENTS.md`: how to work
- `PRD.md`: what to do
- `执行顺序.md`: what to do first today

## 4. Keep pages for display and the desktop for entry points

- `神驴页面` is for page viewing
- `铁胆神驴Codex` is for organization and rules
- Do not spread the same kind of entry point across too many places

## 5. Keep English backups only for key files

Prefer English backups for:

- `README`
- `PRD`
- `AGENTS`
- `分类索引`

Do not duplicate everything; it only adds maintenance cost.
