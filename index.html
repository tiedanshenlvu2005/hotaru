安全任务启动器

这里不是直接执行电脑任务的聊天机器人，而是把你的想法整理成一段清楚、安全、适合粘贴到新 Codex 聊天里的任务指令。

安全版原则：网页只生成提示词，不读取你的电脑文件，不保存 API Key，不直接操作系统。真正执行任务仍然交给 Codex 聊天窗口。

神驴任务输入

Superpowers
使用 Superpowers 的方式，先调研，再写方案，最后执行。

三步工作法

1

先调研

先看资料、文件和现状，整理出可用信息、风险和不确定点，不急着动手。

2

再写方案

把目标、步骤、边界和验证方式写清楚，和你确认以后再进入执行。

3

最后执行

确认方案后再修改文件、生成内容、整理资料或安装工具，并检查结果。

完成后检查

文件是否生成到正确位置，文件名是否清楚，入口是否能打开。
内容标题、结构、重点、格式是否完整，没有明显错漏。
风险是否涉及删除、覆盖、密钥、隐私或系统设置。
验证能测试就测试，不能测试就说明原因和剩余风险。
遗漏最后列出还缺什么、下一步建议做什么。
