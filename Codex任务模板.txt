Codex任务模板

使用 Superpowers 的方式，先调研，再写方案，最后执行。

具体任务：
【写文档 / 改代码 / 整理文件 / 生成表格 / 搭建页面 / Automations自动任务 / 长期任务 / 状态指示器】

执行模式：
【选择一个】
1. codex --full-auto
2. codex resume
3. codex --sandbox read-only
4. codex --profile + 名词

profile 名词示例：
文档、代码、设计、整理、学习、电脑管家、自动化、长期任务、状态助手。

素材位置：
【把文件夹、网页、图片或文档位置写在这里】

输出结果：
【网页 / 文档 / 表格 / 整理后的文件夹 / 代码修改 / 检查报告 / 自动任务方案 / 状态页面】

Automations长期任务设置：
【按计划自动唤醒 / 每天监控 issue / 定期检查文件夹或网页 / 后台 Agent 状态汇报】

状态指示器需求：
【显示正在做什么 / 是否完成 / 有无风险 / 下次唤醒时间 / 自定义宠物形象】

执行前请先告诉我：
1. 你调研到了什么。
2. 准备怎么做。
3. 有哪些风险。

等我确认后再动手。

安全要求：
1. 不删除文件，除非我明确确认。
2. 不覆盖重要文件，先备份或另存。
3. 不输入密码、支付信息、API Key。
4. 不替我完成账号授权、付款、发布。

完成后检查：
1. 检查文件是否生成。
2. 检查内容是否完整。
3. 检查链接或入口是否可用。
4. 检查有没有遗漏。
5. 如果是 Automations，检查计划、频率、目标和汇报方式是否写清楚。
6. 告诉我结果放在哪里。
